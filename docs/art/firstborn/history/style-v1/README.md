# Style guide, version 1 (2026-11-03)

This is the first version of the gate 2 style guide, kept as the owner asked. It's "a solid start", with these issues
to fix in version 2:

1. **The perspective is a bit off.** The head reads as a profile, but the horns and the feet are spread out as if seen
   from the front or the side.
2. **The body parts don't join well.** The wings, tail, horns and legs look stuck on, with seams.
3. **The tail flame should be bigger.**
4. **The helmet only shifts or tilts as a flat piece in the "helmet acts" set.** It clips the head instead of looking
   drawn over it.

The files here are copies:
- `02-style-guide.html` and `.png` are the previews.
- `02-style-guide.md` is the guide.
- `brim_rig.py`, `poses.py` and `ready.paintover.txt` are the 2D rig and poses that drew it.

The copied rig still imports `pixkit` from `../../tools`, so it isn't meant to be re-run from this folder.
